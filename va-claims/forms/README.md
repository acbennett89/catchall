These are the official fillable PDFs as published by VA. Each was downloaded on 2026-10-09 from `https://www.vba.va.gov/pubs/forms/<file>`, except VA 10182, which came from `https://www.va.gov/vaforms/va/pdf/VA10182.pdf`. VA revises forms periodically, so check [va.gov/find-forms](https://www.va.gov/find-forms/) for the current edition before you file.

## `dbq/`: Disability Benefits Questionnaires

There are 71 public DBQs, taken from the list at https://www.benefits.va.gov/compensation/dbq_publicdbqs.asp. A DBQ is the exam form an examiner fills out for a specific condition, and its fields line up with the rating criteria in 38 CFR Part 4. A private doctor can complete a public DBQ, and the veteran can submit it as evidence.
